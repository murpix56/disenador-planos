# Diseñador de planos

Herramienta personal para preparar planos de itinerarios y cortes de calle (por ejemplo, para redes sociales).

- **Fondos:** plano gris y blanco (calles dibujadas con el callejero de OpenStreetMap), plano de calles y satélite (PNOA, IGN).
- **Trazo que sigue las calles:** marcas el inicio, el final y puntos intermedios; la ruta se ajusta a la forma real de la calle.
- **Personalización:** color, grosor, borde, discontinuo, flechas de sentido (color, tamaño, separación).
- **Nombres de calle:** se proponen solos, uno por calle del recorrido; texto, tamaño, color, borde, giro y posición (se arrastran).
- **Descarga:** imagen PNG (cuadrada, vertical, horizontal o HD) de la zona encuadrada. Disponible con el plano gris y blanco.
- El trabajo se guarda en el navegador; también se puede guardar y abrir como archivo `.json`.

Sitio estático: no necesita servidor. Con GitHub Pages: *Settings → Pages → main / root*.
